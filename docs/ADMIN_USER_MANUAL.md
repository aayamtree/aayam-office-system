## 1. Getting Started

### Login
1. Open the app URL in your browser
2. Enter your **email** and **password**
3. Click **Login**
4. You'll land on the **Dashboard**

### Navigation
- **Sidebar** (left) — Main navigation, always visible on desktop
- **Header** (top) — Search bar, notifications bell, quick actions
- **Hamburger menu** (☰) — Toggle sidebar on mobile/tablet

### Your Profile
- Click your **name/avatar** at the bottom of the sidebar
- Options: **Profile** (edit your info), **Settings**, **Log out**

## 2. Dashboard (Overview)

**Path:** Sidebar → **Overview**

The dashboard gives you a bird's-eye view of the entire business.

### What You See
| Section | Description |
|---------|-------------|
| **Quick Stats** | Total jobs, pending amount, active clients, overdue count |
| **Pipeline Overview** | Jobs in each stage (New → Design → Print → QC → Dispatch → Done) |

## 3. Projects & Jobs

**Path:** Sidebar → **Projects & Jobs**

This is the core module — every order/project is tracked here.

### Jobs Overview
- Shows **all jobs** with filters for Stage, Priority, and search
- **Card View** (grid) and **Table View** (list) — toggle with icons at top-right
- Color-coded priority: 🔴 Urgent, 🟡 High, 🟢 Normal

### Creating a New Job
1. Click **"+ New Job"** (top-right)
2. Fill in:
   - **Client** — Select existing or click **"+ Add"** to quick-add
   - **Job Type** — Select or click **"+ Add"** to create new
   - **Project Name** — Name of the work
   - **Quantity, Rate, GST** — Auto-calculates total
   - **Deadlines** — Client deadline + internal deadline
   - **Priority** — Normal / High / Urgent
3. Click **"Create Job"**

### Quick Add Modals (+ Add buttons)
When creating a job, you can quick-add these without leaving the form:
- **Client** — Name + Phone required
- **Job Type** — e.g., "Design Only", "Print + Design"
- **Product Category** — e.g., "Stationery", "Packaging"
- **Product Type** — e.g., "Business Card", "Brochure"
- **Vendor** — For outsourced work
- **Priority** — Custom priority levels
- **Job Stage** — Custom pipeline stages

### Job Details
Click any job card to see:
- Full job info, timeline, file attachments
- **Stage tracking** — Move job through pipeline stages
- **Payment status** — Track advance/balance
- **QC Checklist** — Quality check progress
- **Notes & remarks** — Team communication

### Production Queue
**Path:** Projects & Jobs → **Production Queue**

- Shows jobs grouped by production stage
- Drag-and-drop to reorder priorities
- Filter by stage: Printing, Finishing, QC, Ready

## 6. Marketing

**Path:** Sidebar → **Marketing**

Full CRM and marketing pipeline for the sales team.

### Sub-pages

| Page | Purpose |
|------|---------|
| **Dashboard** | Marketing KPIs — leads, conversions, targets |
| **Leads** | All leads with status tracking (New → Contacted → Qualified → Converted) |

| **Quotations** | Create and send quotations to leads/clients |

1. Go to **Marketing → Leads**
2. Click **"+ Add Lead"**
3. Fill: Name, Phone, Source (walk-in, referral, online), Notes

1. Go to **Marketing → Quotations**
2. Click **"+ New Quotation"**
3. Select client/lead, add items with rates
4. Generate PDF for WhatsApp/email sharing

### Commission Calculator
- Go to **Marketing → Commissions**
- Calculates commission based on order value
- Supports **configurable GST rates**
- Tracks eligibility and payment status

## 7. CRM (Clients)

**Path:** Sidebar → **CRM → Clients**

Master client database.

### Client Management
- **Search** by name, phone, company, or brand name
- **Filter** by client type (Regular, Premium, Corporate)
- **Brand Name** search — find clients by brand (e.g., #tiger, #cobra)

### Adding a Client
1. Click **"+ Add Client"**
2. Required: **Name**, **Phone**
3. Optional: Company, Email, City, State, GSTIN, Address, Brand Name
4. Click **"Save"**

### Client Details
- **Job history** — All jobs for this client
- **Payment history** — Outstanding balance, payments received
- **Contact info** — Phone, email, WhatsApp quick-link
- **Notes** — Internal notes about the client

## 8. Sales & Finance

**Path:** Sidebar → **Sales & Finance**

Complete financial management system.

### Sub-pages

| Page | Purpose |
|------|---------|
| **Overview** | Financial dashboard — revenue, expenses, profit summary |
| **Quotations** | Create/manage price quotations |
| **Orders** | Sales orders linked to jobs |
| **Invoices** | Generate GST invoices for clients |
| **Payments** | Record incoming payments |
| **Banking** | Bank account management & transaction categorization |
| **Purchase Bills** | Track vendor bills & purchases |
| **Vendors** | Vendor master list |

### Creating an Invoice
1. Go to **Finance → Invoices**
2. Click **"+ New Invoice"**
3. Select **Client** and **Job**
4. Add line items (description, quantity, rate, HSN code)
5. **GST auto-calculates** (CGST+SGST or IGST)
6. Save → Generate PDF

### Recording a Payment
1. Go to **Finance → Payments**
2. Click **"+ Record Payment"**
3. Select Client, Invoice, Amount, Payment Mode (Cash/UPI/Bank)
4. Payment auto-updates job payment status

### Banking
- **Add bank accounts** — Name, Account No, IFSC, Balance
- **Categorize transactions** — Income/Expense categories
- **Opening balance** — Set starting balance for accounts
- **Daily finance view** — Cash position across all accounts

### Vendor Management
- Add/edit vendors with contact info
- Track outstanding payables
- Record vendor payments with references

## 9. Dispatch

**Path:** Sidebar → **Dispatch**

Track shipments from factory to client.

|------|---------|
| **Command Center** | Active dispatches with live status |
| **QC & Packing** | Quality check and packing verification |
| **Delivery History** | Past deliveries with proof of delivery |

### Creating a Dispatch
1. Go to **Dispatch → Command Center**
2. Click **"+ New Dispatch"**
3. Select Job, Client, Transporter
4. Add: Vehicle No, Driver, Tracking, Expected Delivery Date
5. Mark stages: Packed → Dispatched → In Transit → Delivered

### QC Checklist
- Before dispatch, verify quality checklist items
- Tick each item as verified
- Auto-updates job status when QC is complete

|----------|--------|

## 17. Tips & Best Practices

### Daily Workflow for Admin
1. ☀️ **Morning** — Check Dashboard for overdue alerts & daily briefing
2. 📋 **Check Production Queue** — Verify job priorities for the day
3. 💰 **Record Payments** — Enter any payments received
4. 📦 **Monitor Dispatches** — Track outgoing shipments
5. 📊 **End of Day** — Review EOD reports from team

### Data Entry Tips
- Always fill **required fields** (marked with *) before saving
- Use **Quick Add (+)** buttons to add new clients/types without leaving forms
- **Search** before creating — avoid duplicate entries
- Use **⌘ + K** for the fastest navigation

### Error Messages
- **❌ Red alert** — Error occurred, read the message and fix the issue
- **✅ Green alert** — Success, action completed
- If a modal **stays open after submit** — there was an error, check the alert message

### Mobile Usage
- All pages are **responsive** — works on phone/tablet
- Use **hamburger menu** (☰) to open sidebar on mobile
- Card view works best on small screens (toggle at top-right of jobs page)
